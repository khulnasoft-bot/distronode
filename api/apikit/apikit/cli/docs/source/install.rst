The preferred way to install the API CLI is through pip:

.. code:: bash

    pip install "git+https://github.com/distronode/distronode/tree/devel/api.git@$VERSION#egg=apikit&subdirectory=apikit"

...where ``$VERSION`` is the version of API you're running.  To see a list of all available releases, visit: https://github.com/distronode/distronode/tree/devel/api/releases
