# Migrating Data Between API Installations

## Introduction

Early versions of API did not support seamless upgrades between major versions and required the use of a backup and restore tool to perform upgrades.

As of version 18.0, `api-operator` is the preferred install/upgrade method. Users who wish to upgrade modern API installations should follow the instructions at:

https://github.com/distronode/distronode/tree/devel/api-operator/blob/devel/docs/upgrade/upgrading.md
